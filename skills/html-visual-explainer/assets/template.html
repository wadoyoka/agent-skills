    __EYEBROW（分野タグ・短く）__

    __見出し前半__、
    __主役の語__をまるっと図解。

    __導入文。「これから何を、どんな順で描くか」を宣言する。 最後に「絵で追えるので、初めてでも迷いません」のような初心者への一言を必ず入れる。__
    __まず全体像：どこを通ってどこへ届く？__

    __むずかしい話に入る前に、流れと登場人物“だけ”を掴ませる。 「それぞれ別の場所・別のタイミングで働くから衝突しない」のような、 後続すべての理解のカギになる一文をここに置く。__

    __「では主役の〜から見ていきましょう」と次章へ橋渡しする。__

    __概念名：一言でいうと何をする？__

    __その概念を、日常の比喩に置き換えて説明する。 専門用語は 用語 で示し、初出時に必ず意味を添える。 一番大事な主張は ハイライト で目立たせる（1段落に1回）。__

    __ファイル名.ext__
    // 最小のコード。全部を見せず「言いたい1点」に絞る
const x = example();
    __見出し：__ __補足・落とし穴・大事なルールを短く。 note（黄・補足）／ note warn（赤・注意）／ note good（緑・うれしい結論）／ note info（青・前提）を使い分ける。__
    まとめ：__一言で全体を回収する__

    __各要素が別々の担当・タイミングで動くから衝突しない、等の締め。__

    __要素__役割働く場所/タイミング
    __A____役割____どこで__
    __B____役割____どこで__
    次の一歩： __「まずは動くものを、次に〜を」のような、読者を前に進める一言。__
