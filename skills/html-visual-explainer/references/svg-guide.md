# SVG 図解ガイド ― 部品の選び方と作り替え方

図解はすべて**インラインSVG**で描く（外部画像・スクリーンショット・アスキーアートは使わない）。
理由: 拡大しても綺麗、テキストが選択でき読み上げ対応、配色を記事と揃えられ、単一ファイルで完結する。

## 部品カタログから選ぶ

`assets/svgs/` に、よくある図の土台を用意してある。ブラウザで `assets/svgs/svg-catalog.html` を開くと一覧で見比べられる。
**14枚とも最初からグラレコ（手描き板書風）で描いてあるので、手描き化の変換は要らない。** 使う手順:

1. カタログで目的に近い部品を選ぶ
2. その `.svg` を開き、`<svg>` タグごと（内蔵の `<style>` も含めて）コピーして figure に貼る
3. ラベル・数（行やステップ）・意味色をトピックに合わせて書き換える

丸ごとその形が合わなくても、部品を「素材」として組み合わせてよい（矢印・箱・ラベルの寄せ集め）。

## 作り替え方

部品は「編集される前提」の骨組み。書き換えるのは主に3つ:

- **テキスト**: `<text>` の中身を実際のラベルに。長い日本語は途中で改行せず、2行に分けたい時は `<text>` を2つ置く（`tspan` でも可）。
- **数**: ステップ・行・象限の増減は、対応する `<rect>`＋`<text>`＋`<line>`のまとまりを複製／削除して座標をずらす。
- **色**: 箱の枠は ink（`#2B2A26`）・塗りは cream/wash に統一し、**意味の色は走る線・主役ラベル・✓/×** に載せる。
  この規則は部品側で既に守られているので、差し替えるのは wash の色とラベルの色だけでよい（`design-system.md` の「図の手描きルール」）。下は意味色（マーカー色）の早見。

意味色（線・ラベル）と wash 塗りのペア:

| 役割 | 線・ラベル（マーカー色） | wash 塗り |
|------|--------------------------|-----------|
| 構造/つなぎ 青 | `#2E7DB5` | `#DDEAF4` |
| 主役/強調・走る線 朱 | `#EA5A3D` | `#FBE1D7` |
| 正しい/ゴール 緑 | `#4E9A51` | `#DEEFD8` |
| 危険/× 赤 | `#C64444` | （淡い赤・控えめに） |
| ハイライト 黄 | `#FFC93C` | `#FFF0C2` |
| 中立の箱 | 枠=ink `#2B2A26` | cream `#FFFDF7` |

## viewBoxと寸法

- `viewBox="0 0 800 H"` を基準にする。幅は800固定、高さHだけ内容に合わせる（170〜300が目安）。CSSで `width:100%` になるので実寸は自動。
- 座標は800×Hの中で考える。box は角丸 `rx="10〜14"`、線は `stroke-width="1.2〜2.5"`。
- フォントは図中もテンプレの3種を踏襲: 強いラベル=Yusei Magic（マーカー体）、補足=Zen Kurenaido（ペン体）、記号/コード=JetBrains Mono。サイズは 11〜16px を目安に、主役ラベルを大きく。
- `text-anchor="middle"` で中央寄せ、`<text>` の `y` はベースライン（見た目の下端寄り）である点に注意。

## 配色

`design-system.md` の配色（マーカー色）と同じ意味づけを図でも厳守する。青=構造/つなぎ、朱=主役/強調・走る線、緑=正しい/ゴール、赤=危険。
主役色（朱）は記事内で一貫させ、あちこち色を変えない（「意味の地図」が壊れる）。

## アニメーション

流れる破線を出したい線に `class="flow"` を付ける。カタログの `flow` 入りSVG
（hero-concept / flow-pipeline / flow-horizontal / stack-blocks / timeline）は、
**各ファイルがアニメーションを内蔵している**ので、カタログ・単体表示・テンプレ埋め込みのどこでも自動で流れる。

```xml
<path class="flow" d="M110 60 L110 250" stroke="#EA5A3D" stroke-width="2.5" fill="none" stroke-linecap="round" stroke-dasharray="8 10"/>
```

内蔵アニメは、SVGルートに一意のidを振り、その配下だけにスコープしたCSSで実現している（他のSVGと混線しないため）:

```xml
<svg id="veHero" ...>
  <style>
    @keyframes veHeroDash{to{stroke-dashoffset:-170}}
    #veHero .flow{animation:veHeroDash 4.2s linear infinite}
    @media (prefers-reduced-motion:reduce){#veHero .flow{animation:none}}
  </style>
  ...
```

- 動かしたい線にだけ `class="flow"` を付ける。全部動くと落ち着かない。
- `prefers-reduced-motion` 環境では自動で止まる（各SVGの `<style>` と、テンプレート側CSS/JSの両方で吸収）。
- コピーは **`<svg>` タグごと（内蔵の `<style>` も含めて）**。中身だけを別の空`<svg>`に貼ると `<style>` が失われて止まるので注意。
- flow入りを自作するときは、ルートに一意のidを付け、上の型の `<style>` を真似る。`stroke-dashoffset` の移動量を破線周期の整数倍にすると継ぎ目なく回る（例: `stroke-dasharray="8 10"`＝周期18 → `-180`）。
- 図の意味はアニメなしでも成立させる（reduced-motion配慮）。

## アクセシビリティ

- すべての図に `role="img"` と `aria-label="この図が何を表すか"` を付ける。装飾でなく情報だから、読み上げで内容が伝わるようにする。
- 色だけに意味を頼らない。赤/緑には「⚠」「✓」やラベル語も添える（色覚多様性への配慮）。
- 文字は画像化せず `<text>` のまま（拡大・選択・翻訳ができる）。

## ゼロから描くとき

カタログに合う型がなければ、次の素材を組み合わせて自作する。

- **紙**: 一番下に `<rect x="0" y="0" width="800" height="H" rx="14" fill="#FBF7EC"/>`
- **箱**: `<rect x y width height rx>`（枠 ink 2.5・塗り cream/wash）＋ 中央に `<text text-anchor="middle">`
- **矢印**: `<path>` の直線 ＋ 先端に **V字2本線**。例: `<path d="M205 98 L214 104 L205 110" fill="none" stroke="#2B2A26" stroke-width="3" stroke-linecap="round" stroke-linejoin="round"/>`
- **曲線の矢印**: `<path d="M.. Q.. ..">`（2次ベジェ）＋ 端に V字。V字の向きは**終点の接線に合わせる**（ずれると刺さっていないように見える）
- **接続点**: `<circle r="4〜10" fill="意味色" stroke="#2B2A26" stroke-width="2">`
- **主役の影**: 本体と同じ `<rect>` を5px右・6px下にずらし `fill="#D9CFB6"` で先に敷く（1図に1つだけ）

作ったら早見表の型のどれに近いか考え、色と意味づけだけは既存部品に合わせると、記事全体で図の“文法”が揃う。
